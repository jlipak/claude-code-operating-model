# Contributing

This is documentation of one operator's setup, so it is opinionated by design. Two kinds of contribution are welcome.

**Issues.** Open one for anything that is wrong, stale, unclear or contradicts another part of the documents. A pointer to the file and the part is enough. Questions about how to adopt a pattern are fine as issues too.

**Pull requests for corrections.** Typos, broken links, a hook that no longer matches the Claude Code hook contract, a command that does not run. Keep a PR to one correction, and run `python scripts/check_links.py` before opening it.

Pull requests that add new patterns, restructure the documents or change their tone will most likely be closed with a thank-you. The documents record what one setup looked like at one time; the README says what changed since.
